# AxiomPilotCode

Локальный агент для редактирования кода. **Версия 1.0.0-alpha.1 — кандидат V1, не стабильный релиз.** Fast и Deep используют одну выбранную модель и один backend. Локальная работа не требует аккаунта. [English](README.md) · [Матрица готовности](docs/READINESS.md) · [Безопасность](SECURITY.md)

Прототип 0.1 расширен модулями TypeScript: runtime llama.cpp, файловые инструменты с разрешениями, контекст, Verify, менеджер моделей и сохранение сессий. Совместимость с внешним LM Studio сохранена. Нет телеметрии, скрытого облачного fallback, фонового сервиса или автоматической проверки обновлений.

## Установка кандидата

Нужны Node.js 22+, npm и Git. Для тестов разработки нужен Python 3.11; для самого CLI он не требуется. Этот кандидат **не опубликован в npm**. Воспроизводимая установка из исходников:

```sh
git clone https://github.com/zaoastronaftik-bit/axiom-pilot-code.git
cd axiom-pilot-code
git checkout feat/v1-candidate
npm ci --ignore-scripts
npm run check
npm test
npm run smoke
npm pack
npm install -g --ignore-scripts ./axiom-pilot-code-1.0.0-alpha.1.tgz
pilotcode --version
pilotcode doctor
```

Сохраните SHA из `git rev-parse HEAD`. Зависимости закреплены lockfile. Публичная установка `npm install -g axiom-pilot-code` станет доступна для этой версии только после отдельного разрешения владельца на публикацию.

## Локальная модель без LM Studio

Установщик рассчитан на Windows x64, NVIDIA и CUDA 12.4. Требуется совместимый драйвер. Целевая приёмочная машина: Windows 11, RTX 4070 SUPER 12 ГБ, RAM 32 ГБ. **Прогона на ней пока нет.**

```sh
pilotcode runtime install
pilotcode models search qwen
pilotcode models download qwen2.5-coder-7b-q4_k_m
pilotcode runtime verify
pilotcode models verify qwen2.5-coder-7b-q4_k_m
pilotcode --backend native --model qwen2.5-coder-7b-q4_k_m --cwd ./my-project --ctx 4096
```

До загрузки показываются источник, размер, лицензия, каталог и удаление. Runtime llama.cpp b11669 с зависимостями CUDA: 658 026 325 байт архивов; Qwen2.5-Coder 7B Q4_K_M: 4 683 073 536 байт. Нужен дополнительный диск для распаковки и временных файлов. Повтор команды продолжает незавершённую загрузку; готовый файл повторно используется после проверки SHA256.

Первое задание: `Найди причину падающего теста, исправь её и проверь результат.` Агент показывает прочитанные файлы. Перед записью прочитайте diff, перед запуском — точную программу и аргументы. `/mode deep` добавляет план и до двух попыток исправления после Verify на той же модели. `/sessions` и `/resume ID` восстанавливают разговор с тем же проектом, моделью и backend. `/undo` отказывается перезаписывать более поздние правки пользователя. Результат менее чем за пять минут после загрузки модели — пока непроверенная цель.

Runtime слушает только loopback, защищён ключом на время запуска и останавливается при штатном выходе CLI. Обнаружение GPU не считается тестом inference: при offload нужны реальные строки выделения памяти в логе. CPU запускается только с `--cpu`. Оценка RAM/VRAM приблизительная; автоматического перехода в swap нет.

## Внешний LM Studio

Установите LM Studio отдельно, загрузите модель с tool calling и включите локальный OpenAI-compatible сервер:

```sh
pilotcode --backend external --url http://127.0.0.1:1234/v1 --model ID_МОДЕЛИ --cwd ./my-project
pilotcode run "Объясни причину ошибки" --backend external --model ID_МОДЕЛИ --json
```

External выбран по умолчанию и явно отображается. `/models` показывает ID сервера; `/model ID` сохраняет прежнюю сессию и начинает новую. Для удалённого HTTPS endpoint требуется отдельное согласие на передачу контекста. Другие совместимые локальные серверы задаются через `--url`, но каждый сервер и модель требуют проверки. `--structured-tools` явно включает строгий JSON-протокол для моделей без function calling; текст модели не превращается в shell.

## Разрешения и данные

Без TTY изменения и команды отклоняются, если не заданы точные `--allow-write path` / `--allow-command '["program","arg"]'`. В интерактивном режиме: разрешить один раз, точную цель на сессию или отказать. `/permissions reset` сбрасывает выдачи. На Windows npm запускается через Node и абсолютный путь npm-cli.js. Разрешённые subprocess имеют права вашего пользователя и доступ к сети — это не песочница.

Ctrl+C отменяет задание; завершённые изменения остаются в проекте и имеют backup. Коды выхода: 0 — завершено, 1 — ошибка, 130 — явная отмена, 2 — исчерпан бюджет либо проверка не прошла. `--json` выдаёт JSONL, включая ID сессии.

Данные: `%APPDATA%/AxiomPilotCode` в Windows; `$XDG_CONFIG_HOME/axiom-pilot-code` или `~/.config/axiom-pilot-code` на Linux. Переопределение: `PILOTCODE_HOME` / `AXIOM_HOME`. Здесь хранятся модели, сессии, backups, аудит и профили. Сессии содержат фрагменты проекта и не шифруются; защищайте локальную учётную запись и диск. Токены аккаунта хранятся отдельно с защитой ОС. Project memory — редактируемый `AGENTS.md`, без автоматического сбора личных сведений.

`pilotcode --help` перечисляет команды. Дополнительно: `verify`, `autotune`, `models import FILE ID --license SPDX --source URL`, `models remove ID`, `runtime remove`, `runtime cleanup`, `update`, `update install`. Обновление выполняется явно, проверяет npm SHA512 и сохраняет пакет отката; реальное обновление опубликованного релиза ещё не проверено. Удаление CLI: `npm uninstall -g axiom-pilot-code`; пользовательские данные сохраняются.

## Необязательная авторизация

Задайте реальный HTTPS API через `--api-url` / `AXIOM_API_URL`, затем `pilotcode login`, `whoami`, `logout`. CLI показывает код, спрашивает разрешение открыть браузер и опрашивает API с установленным интервалом. Пользователь отдельно подтверждает код на сайте. CLI не подтверждает себя. Windows использует DPAPI, Linux — `secret-tool` и Secret Service; интеграция хранилища macOS пока отсутствует. Без работающего API выводится недоступность сервиса. Дополнены серверный отзыв токенов и интерфейс аккаунта в репозитории сайта. Живой вход с БД и тестовым аккаунтом остаётся обязательным критерием. [Контракт и приёмка](docs/ACCOUNT.md).

## Профиль и зашифрованная передача чатов (экспериментально)

На сайте доступна отдельная страница [«Мой профиль»](https://zaoastronaftik-bit.github.io/axiom-pilot-code.PAGES/profile.html): никнейм, список установленных компонентов/моделей и сохранённые чаты. Браузер хранит локальный снимок в IndexedDB; после первого получения он доступен офлайн на том же устройстве. Статические файлы страницы кэшируются Service Worker, API-ответы не кэшируются.

**Обмен не включён по умолчанию.** Сначала войдите в аккаунт через сайт, откройте профиль (публичный ключ шифрования генерируется в браузере), затем привяжите CLI:

```sh
pilotcode login
# Подтвердите показанный одноразовый код в разделе настроек сайта.
pilotcode whoami
pilotcode --sync-history --cwd ./my-project
```

CLI хранит токен привязки в защищённом хранилище ОС. Опция `--sync-history` включает разовый зашифрованный снимок перед стартом сессии; альтернативно для доверенного локального окружения `AXIOM_SYNC_HISTORY=1`. Передаются только метаданные встроенных инструментов/локально установленных моделей и **до 12 последних чат-сессий по 24 сообщения и 1000 символов на сообщение**. Команды, tool-output, системные инструкции, каталог проекта и сами файлы проекта не пересылаются. Некоторые секреты редактируются регулярными выражениями, но это **не гарантирует** отсутствие всех ключей/PII в пользовательских сообщениях: включайте историю только для доверенных сессий. Для чистого локального запуска не указывайте этот флаг.

CLI получает открытый RSA-OAEP-3072 ключ профиля и шифрует снимок случайным AES-256-GCM ключом. AES-ключ оборачивается RSA-OAEP-SHA256. Закрытый RSA-ключ неэкспортируемый и хранится в IndexedDB на устройстве браузера; на сервере видны только открытый ключ и шифротекст. Relay принимает до 15 отправок на CLI-токен в час, хранит максимум 20 ожидающих пакетов пользователя, удаляет их после подтверждения браузером или через 24 часа (очистка каждые 15 минут). Дубликат снимка без изменений не отправляется. Ошибки синхронизации не препятствуют локальной работе CLI.

**Ограничения:** новый браузер или очистка IndexedDB лишают доступа к ранее зашифрованным пакетам; переноса закрытого ключа пока нет. Локальные копии в IndexedDB защищены механизмами самого браузера и ОС, а не отдельным паролем. Работа `pilotcode login` с реальными системными хранилищами Windows/Linux и длительная синхронизация на пользовательском ПК требуют дополнительной проверки. Нельзя считать этот механизм облачным резервным копированием чатов.

## Проверки и ограничения

```sh
npm run check
npm test
npm run smoke
python -m unittest discover -s training -p "test_*.py"
npm run pack:dry
npm run smoke:package
npm audit --omit=dev --audit-level=moderate
```

Тесты CLI включают SSE, разрешения, symlink/race-конфликты, undo, ZIP, download resume и реальные падающие/исправленные проекты Node/TypeScript/Python. Smoke использует тестовый HTTP-сервер и не доказывает работу LLM/GPU. В CI предусмотрены Windows/Linux Node 22/24 и отдельный GPU job.

[AxiomBench](bench/README.md): 24 проверяемые задачи и runner baseline/agent, без выдуманных результатов. [AxiomTune](training/README.md): отдельные opt-in QLoRA/PEFT скрипты, валидатор и экспорт LoRA; обучение и экспорт на GPU здесь не выполнялись.
